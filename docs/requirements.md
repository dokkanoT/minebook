# 要件定義

## プロジェクト概要

MineBook — 古本との出会いを、持ち帰れる本棚へ。

古本屋で見つけた本をスマホでスキャンして記録し、PC の本棚に並べて楽しむ Web アプリです。

## 機能要件

### スマホ

- ISBN バーコードのスキャン（カメラ）と手入力
- 書籍情報の自動取得（openBD / 楽天ブックス API）
- 店頭価格からお宝度（S / A / B）を判定
- 購入・保留・見送りを選んでコレクションに保存
- 保存した本の一覧（ホーム）

### PC（デスクトップ）

- ダッシュボード
- バーチャル本棚（棚への配置・並び替え）
- コレクション管理（タグごとにまとめる）
- ランキング
- 発掘履歴（保存した本）
- 関心分析

### 共通

- ログイン・新規登録（メール + パスワード、Google）
- 端末による振り分け（スマホは `/home`、PC・タブレットは `/dashboard`）

## 非機能要件

- スマホは縦長の画面、PC は横長の画面に合わせる。どちらの画面も、もう片方の幅で崩れない程度にはする
- カメラを使うため https で公開する
- Supabase による認証・データ管理（RLS で自分のデータだけを読み書きできる）
- Vercel へのデプロイ

## 決まっていないこと

- お宝度の正式な判定ルール（いまは割引率で仮に決めている）
